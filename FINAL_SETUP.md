### How Variables Are Sent

When user clicks "Begin Analysis", the app sends:

**1. User's Original Prompt** → as `user` field

**2. Optimization Guidelines** → as `variables.optimization_guidelines`, which includes:
   - Intent Lock (optimization preferences)
   - Selected Review Modes with descriptions

Example:
```
Use clear language.
Maintain original intent.
Improve structure and clarity.

Review Modes:
- Context Flow: Checks usage before definition, forward references...
- Redundancy: Finds repeated instructions and suggests consolidation
- Token Reduction: Shortens phrasing without losing meaning
- Contradictions: Detects conflicting instructions
- Structure: Role · Goal · Context · Constraints · Output Format
```

## 🐛 Troubleshooting

### If you see errors:

1. **"Failed to optimize prompt"**
   - Check: Is `.env` file present?
   - Check: Does it have `VITE_API_KEY=2aa0ba781f34d005b101909439765967`?
   - Solution: Restart dev server after creating/updating `.env`

2. **"API Error: 401"**
   - Check: API key might be invalid
   - Solution: Verify the key in `.env` file

3. **"Network error"**
   - Check: Internet connection
   - Check: API endpoint is accessible

4. **Blank screen or can't see the response**
   - Check browser console for errors (F12)
   - Try refreshing the page
